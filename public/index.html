Three ways to share

You decide what each link allows

View only

Clients browse a clean full-screen gallery. No download buttons, no direct image addresses, right-click and drag disabled, optional watermark overlay.

View & download

Clients can save single photos or the whole gallery as one ZIP, only when you switch downloads on.

Full access

Everything open: view, download and save. Ideal for delivering final files to a client.

How it works

Create a gallery

Name it, drag in your photos, and watch the upload progress.

Set the rules

Pick an access mode, add a password, and optionally an expiry date.

Send the link

One unguessable link per gallery. Revoke or replace it any time.

Honest about protection

Original files stay in private storage and are only sent after the visitor has the right link and password. View-only galleries add real deterrents, but no website can fully stop screenshots or someone photographing a screen with another phone. Use watermarks and download-enabled modes accordingly.
